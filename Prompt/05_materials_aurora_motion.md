# ArkTerminal · Prompt 05：原生窗口材质、动态极光与动效

版本：2026-10-30 · 原始十阶段增强版

使用方式：将本文件全文交给实施 Agent，并明确要求执行本阶段。本文件已包含必要约束与验收，可独立作为阶段 Prompt；运行依赖仍需前序阶段提供。当前交付内容是规划文档。

## 一、任务梗概

实现清晰、可配置且不拖慢输入的视觉系统。极光随聚焦/失焦等窗口活动平缓变化，首版包含背景图三项控制和一键性能模式。

## 二、前置条件与任务范围

**前置条件：**正式终端渲染/IME 和多标签稳定；了解 D3DImage 的 alpha/设备边界，具备 Windows 10/11 能力探测环境。

**本阶段包含：**主题资源、真实窗口材质、背景图/遮罩/模糊/位置、活动驱动极光、可中断动效、性能模式及系统减弱动效适配。

**阶段边界：**高对比主题、色弱友好配色、专用减少透明度选项后续加入；工作区独立极光色等待工作区功能。首版仍保证文字可读与系统减弱动效。

## 四、任务要求

1. 建立 Theme/Brush/Spacing/Typography 资源，亮/暗/跟随系统；切换与系统消息处理不重建终端会话。
2. 按 Windows 能力选择受支持的窗口材质，区分 Mica/Acrylic、桌面真实透明与应用内半透明层。验证 DWM 与 D3DImage alpha 链路，不把 BlurEffect 冒充桌面采样，不使用不可靠 API 伪报支持。
3. 提供关闭毛玻璃、关闭应用背景以显示后景、亮度/饱和度/可控模糊范围；不能实现的系统参数给明确能力说明。透明后不穿透点击，文字保持足够对比。
4. 极光随聚焦/失焦等窗口活动做平缓低成本变化，至少 4 套多色预设并允许自定义。不按输出节奏闪烁；失焦降帧，最小化或可靠遮挡时暂停。
5. 背景图上传/清除、遮罩、模糊、位置与适配。校验真实格式、文件大小与解码像素上限，复制至当前数据根，便携模式用相对资源路径；坏图不阻塞启动。
6. 页面/弹层 150—250ms，进入 ease-out，可中断；高频键盘操作不等待动画。尊重系统减弱动效；完整高对比与色弱主题到后续版本再做。
7. 首版一键性能模式关闭极光、透明/模糊、阴影、非必要动效，切换可恢复原偏好；不影响会话、字体、内容和输入。

### 外观与性能契约

- 原始动效参考为 emilkowalski/skills：取其交互与动效原则，转换为 WPF 实现，不安装或复制 Web 技术栈。
- 亮/暗/跟随系统，页面和弹层约 150–250ms，进入 ease-out、可中断；高频键盘操作不等动画。首版尊重系统减弱动效，完整可访问性主题在后续版本加入。
- 极光由窗口活动驱动颜色强度/透明度/低成本位移的平滑过渡；不随每次输出闪烁。失焦降低强度与帧率，最小化/可判断遮挡时暂停；无法可靠判断遮挡时保守降帧。
- 一键性能模式关闭极光动画、透明/模糊、阴影及非必要动效，但保留终端内容、选择和会话生命周期。
- DWM backdrop、桌面后景透明、应用内背景图模糊是不同能力。系统 API 没有任意调节范围时，滑块只作用于真实可控层并标明范围；不把 Mica 壁纸采样、WPF BlurEffect 或纯透明称为任意桌面实时模糊。
- Windows 10/11 材质按能力降级。真实透明需在桌面移动窗口后验证；不支持时明确显示能力限制并保留可读的半透明/不透明模式。
- 全局命令面板默认 Ctrl+Shift+Space，可更改/禁用，冲突提示；Quake 不在首版。面板失焦时呼出可激活应用，但不创建终端进程。

### 材质与性能的实现要求

- 背景层、终端文字层、选择/光标层各自职责明确。高成本模糊只用于合适的背景/静态图层，不对每个字符、标签或每帧文本施加 BlurEffect。
- 区分“清除背景图”“关闭极光”“关闭毛玻璃”“透出窗口后景”；开关应真实对应可观察行为，参数不支持时给出能力说明，不能保存一个不生效数值。
- 预设至少 4 套多色极光，允许修改色值；聚焦/失焦的变化平缓、可打断。输出吞吐不是动画触发器，隐藏窗口不得持续满帧。
- 背景文件校验扩展名、真实解码格式、像素尺寸及大小；图片读取/缩放离开 UI 热路径。资源复制到当前数据根，删除只处理应用拥有的副本，不删用户原图。
- 性能模式是覆盖当前视觉策略，退出后还原用户原偏好；不能把全部设置永久重写为关闭，也不允许关闭模式时丢失终端内容。
- 常规 UI 进入动画采用 ease-out、150—250ms；拖拽动画可中断，键盘切标签与输入立即响应。仅动画低成本变换/透明度，避免每帧触发布局测量。
- 在不同 Windows 能力下分别列出实际材质与回退结果，平台限制与功能完成度如实记录。
