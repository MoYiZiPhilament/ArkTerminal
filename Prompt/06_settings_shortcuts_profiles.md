# ArkTerminal · Prompt 06：设置页、外观编辑与快捷键

**本阶段包含：**外观/快捷键/配置页面、即时预览/保存/取消、Profile 校验、基础字体编辑、性能面板和预览后诊断导出。

## 四、任务要求

1. 设置含外观、快捷键、配置，并为诊断/数据管理提供清晰入口；滚动、即时预览、保存、取消、恢复默认语义一致，失败可见，草稿独立恢复。
2. 外观连接全部 阶段 5 控制及终端/UI 字体、字重、字号、行高、字距/连字。时间戳、逻辑行号、命令耗时为各自开关，默认关闭；耗时无可靠边界时显示未知。辅助列不改变终端列宽或污染复制文本。
3. 统一快捷键路由，列出复制、粘贴、全选、搜索、滚动、清屏、字号及标签操作。Ctrl+C 保留中断语义；全局热键可改/禁用，其余首版不增加复杂编辑器。
4. Profile 编辑完整支持命令/参数、名称、图标、启动后执行、cwd、{{home}}、环境变量、管理员、Shell 集成与 Agent 配方。环境行按首个等号切分，校验名称、重复键、路径/权限，敏感值不写诊断。
5. 解释清屏视图/清回滚与实际给 Shell 发命令的区别；设置启动后执行不等于替换 Shell。管理员能力未验证时禁用并显示原因。
6. 默认隐藏的性能面板显示实际采样 FPS/重绘率、输入输出吞吐、队列深度、缓冲占用、进程内存/句柄。共享渲染资源与 per-session 估算标清口径，不伪装精确会话内存。
7. 一键诊断导出生成可编辑/可检查预览，默认含版本、能力、错误、性能计数，排除正文、完整命令与环境变量；脱敏路径，限制大小，轮换并可清理。不要为诊断新增独立报告脚手架。

### 设置生效与编辑事务

| 字段类别 | 应用时机 | 验收要点 |
| --- | --- | --- |
| 主题/背景/字体 | 当前编辑预览；保存才持久化 | 取消恢复原值，草稿恢复不自动保存 |
| 默认启动 Profile、命令/cwd/环境变量 | 下次主动新建/重启会话 | 不悄悄重启正在运行的进程 |
| 全局热键 | 验证并成功替换注册后生效 | 冲突保留旧可用值或明确禁用，结果可见 |
| 历史/输出记录 | 对应服务就绪后按明确操作启用 | 不因打开设置或恢复草稿而自动记录 |
| 管理员/Shell 集成/Agent 参数 | 消费方就绪后用于新启动 | 未就绪显示原因，不伪装功能可用 |

- 环境变量按首个等号划分名称和值，保留值内等号和有效空格，重复键处理明确；无效行给行内定位。
- `{{home}}` 只在允许的路径字段展开；变量名白名单、不递归执行表达式。区分 Shell 启动参数与“启动后执行”的原始脚本，不二次意外求值。
- “清屏”需标明只清当前视图、清除回滚或向 Shell 发命令；不能劫持 Ctrl+C。复制使用 Ctrl+Shift+C，无选区时不自动复制整段秘密输出。
- 时间戳、逻辑行号、耗时各自默认关闭；作为辅助显示，不改变终端列宽或进入复制正文。无可靠边界的耗时显示未知。
- 性能面板必须明确口径：进程内存是整体；会话内存是可归属缓冲等估算，共享图形资源不能重复计费。隐藏后减少采样，避免诊断功能自身变成瓶颈。
- 诊断预览可取消且无正文落盘；导出只保存最终确认的诊断内容，不能把会话转录目录打进诊断包。
