# ArkTerminal · Prompt 07：Shell 集成与管理员启动

版本：2026-10-30 · 原始十阶段增强版

使用方式：将本文件全文交给实施 Agent，并明确要求执行本阶段。本文件已包含必要约束与验收，可独立作为阶段 Prompt；运行依赖仍需前序阶段提供。当前交付内容是规划文档。

## 一、任务梗概

补齐 Shell 的 cwd/命令状态、链接与通知、按需历史/转录以及真实管理员会话。所有状态基于实际能力，提权始终走 Windows UAC。

## 二、前置条件与任务范围

**前置条件：**阶段 2/3 的生命周期与输入可用，阶段 4/6 的状态/配置入口已建立。四种 Shell 与提权测试环境就绪；有 MSIX 工具链时提前做最小包身份兼容探测。

**本阶段包含：**四种 Shell 注入集成、可靠命令信号、可点击路径/URL、失焦通知、应用历史开关、按会话输出保存、提权辅助器及受限 IPC。

**阶段边界：**命令级折叠/结果块导航与跨会话高级历史搜索后续深化；本阶段提供真实边界事件。通知音后置。实际 MSIX/ZIP 最终打包在阶段 10。

## 四、任务要求

1. 分别实现 PowerShell 5/7、CMD、Git Bash 的可关闭集成：cwd、命令边界、退出码、标题。只用应用数据/临时脚本及启动注入，不改永久 profile、bashrc 或注册表。能力有限时逐项降级，不猜状态。
2. Shell/OSC 信号是进程提供的非可信元数据，只用于显示/有界记录，不能凭此授权执行、读文件或泄露上下文。命令状态与 Agent 细状态分离。
3. 文件路径和 http/https URL 可点击，正确解析空格、引号、Windows 路径与可用 cwd；本地路径行动前展示完整目标，拒绝隐蔽控制字符与任意自定义协议。打开不可用文件给出实际错误。
4. 命令完成、长任务结束、可靠等待输入通知仅在应用窗口失焦时发送，各类可关闭、去重/限频；无可靠事件不通知。默认长任务门槛 10 秒，可配置。首版无声音。
5. 默认只使用 Shell 历史。应用历史单独开启，依据可靠边界保存并设条数/字节上限、清除入口；Shell 历史不被擅自批量导入。无法取得边界时不保存猜测记录。
6. 按会话手动开启输出转录，默认关闭且状态明显；支持停止、清除、单会话/总量/期限限制，写盘有界且故障不阻塞终端。按本文件的数据持久化约定默认值实施并说明动态画面的限制；关闭后不再写正文，不持久化按键。终端保存不能进入诊断或自动进入 MCP。
7. 管理员会话由独立 UAC 辅助器创建并拥有提权 ConPTY，以当前用户受限 IPC 通信；鉴别对端、绑定已确认的一次启动请求、限制句柄/命令复用及生命周期。不要只把高权限进程挂到普通 ConPTY 后声称成功。
8. 提前验证 MSIX 与 ZIP 中的提权路径、清单能力和系统限制。取消 UAC 不留孤立进程；不可可靠支持时明确禁用并记录发布阻塞/平台限制，不用独立黑窗伪装嵌入终端。

### 集成信号与数据持久化约定

为四种 Shell 分别列出实际能力：cwd、命令开始/结束、退出码、标题、启动后脚本。CMD 能力不足时提供具体降级，不把输出提示符猜测当可靠事件。集成关闭后不得残留注入脚本行为，用户原有 profile/bashrc 内容不被重写。

链接点击只处理已允许的本地文件与 http/https；解析出显示文本之外的真实目标并展示。相对路径需已知 cwd，否则标为无法解析；错误码跳转没有可靠规则时不造链接。

应用命令历史开启后可提供有限本地历史查看/搜索，默认仍沿用 Shell 自身历史。输出记录以文本转录/有界命令片段为基础，光标覆盖、备用屏幕不保证逐帧重放；是否截断要可见。

### 提权边界

- 辅助器由 UAC 提权并拥有提权进程及 ConPTY，UI 通过受限本机 IPC 控制已确认目标会话；启动请求绑定可执行文件、参数、cwd、运行模式及唯一会话，不接受任意后续命令复用。
- 校验通信对端、协议版本、消息长度、连接寿命与关闭信号；当前用户 ACL 是基础，不代表所有同用户进程天然可信，不按客户端自报 PID/名称授权。
- UAC 取消、连接超时、UI 崩溃、辅助器退出均收束到清晰状态，普通会话不受影响。对退出时仍在运行的高权限进程有明确回收/提示策略。
- ZIP 与 MSIX 的可用能力分别验证。若当前包模型不能可靠承载提权，不提供伪成功或另开黑窗；保留普通模式，并把该项明确列为限制/发布阻塞。

### 数据持久化约定

| 数据 | 默认状态 | 开启后的建议上限 | 边界 |
| --- | --- | --- | --- |
| 内存回滚 | 启用 | 10,000 行，另有独立内存字节预算 | 超出容量淘汰旧回滚，不丢待解析 VT 字节 |
| 应用命令历史 | 关闭 | 1,000 条、1 MiB，取先到者 | 仅可靠命令边界；可关闭、清除，不批量导入 Shell 历史 |
| 会话输出转录 | 每个新会话关闭，手动开启 | 每会话 10 MiB、总量 100 MiB、7 天同时生效 | 记录开启后的有界文本，不记录原始按键；可停止、清除 |
| 诊断日志 | 必要诊断、有界 | 配置集中管理大小和保留期 | 默认排除正文、完整命令、环境变量和秘密 |

转录文件不承诺复现所有动态覆盖/备用屏幕画面，也不用于恢复运行进程。记录可能含程序回显的秘密；启用入口明确说明内容范围，不宣称自动脱敏万能。达到上限轮换并提示截断，写盘失败停止记录而不阻塞终端。开启历史或转录不会自动扩大 MCP/Skill 的读取范围。
