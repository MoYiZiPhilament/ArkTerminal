## 一、任务梗概

实现真实可交互的 ConPTY 会话、顺序解码/VT 解析和有界屏幕缓冲。重点是四种 Shell 的进程生命周期、输入输出正确性与关闭响应。

## 二、前置条件与任务范围

**前置条件：**阶段 1 的数据根、Profile/启动请求与 Session 接口可用。准备 Windows 交互环境；CMD、PowerShell 5/7、Git Bash 分别记录是否安装。

**本阶段包含：**ConPTY 创建/resize/退出、进程参数、UTF-8 增量解码、VT 状态机、屏幕/回滚模型、基础输入、最小行级绘制。

**阶段边界：**正式 DirectWrite 渲染与完整中文 IME 在阶段 3；多标签在阶段 4；Shell 语义集成和管理员会话在阶段 7。

## 四、任务要求

1. 使用 ConPTY 与 STARTUPINFOEX/进程属性创建独立会话，控制继承句柄，释放父进程多余端点。HPCON 与普通 HANDLE 分别按正确 API 管理。
2. 遵循 ConPTY 同步端点约束，以独立读写工作线程/安全队列隔离阻塞；支持取消阻塞读写、启动失败回滚、resize 与并发关闭。关闭时仍有序排空输出以避免死锁，不在 Dispatcher 上等待 ClosePseudoConsole。
3. 启动请求结构化；针对 CMD、PowerShell 5/7、Git Bash 分别编码命令行、环境块与 cwd。明确子进程树的关闭策略，只处理本会话拥有的进程，不误杀外部进程。
4. 使用有状态 UTF-8 Decoder，处理跨读边界、非法字节和流结束。实现 VT 状态机：C0、CR/LF、Tab、Backspace、CSI/OSC、SGR、光标、擦除、滚动区域、自动换行、主/备用屏幕及必要模式。
5. 对序列长度/参数数目设上限，截断或忽略未知序列而不崩溃，诊断只记类型/计数，不记录原始敏感 payload。OSC 52 等剪贴板或外部副作用默认禁止。
6. 屏幕模型支持宽字符续格、组合序列和有界回滚；按序解析全部字节，渲染通知可合并。后台标签保持输出接收与状态更新，不忙循环。
7. 用临时简单的行级绘制接通基础键、方向/功能键、Ctrl/Alt、粘贴；不为每个字符创建 TextBlock。阶段 3 完成后移除临时路径。

### 输入、进程与状态契约

- 支持 CMD、Windows PowerShell 5、PowerShell 7、Git Bash；分别列入验收，不能用“三种 Shell”掩盖 PowerShell 两个版本。
- ConPTY 端句柄按 Windows API 的同步通信约束创建；应用层通过独立读写工作线程/队列等方式实现 UI 非阻塞与可取消生命周期，不能把同步句柄强行当作 Overlapped 异步句柄。
- 输出按序解码与解析；有界队列通过背压控制，不能为保帧率任意丢 VT 字节。可以合并渲染通知、限速重绘、丢弃已超出容量的旧回滚内容。
- ConPTY 子进程创建涉及 CreateProcess/STARTUPINFOEX。启动请求先结构化，最终按目标程序、Shell 和脚本各自的语法编码；`ArgumentList` 只解决适用调用层，不代表嵌套 PowerShell/CMD/Bash 引号已安全。
- Unicode 以标量、字形簇和终端列宽协同处理，选择/搜索/删除不得拆开代理项或组合序列。声明明确的 Unicode/宽度策略与已知兼容差异，不承诺所有程序对 emoji 宽度一致。
- Ctrl+C 保留 Shell 中断语义；复制/粘贴默认 Ctrl+Shift+C/V。功能键与 IME 文本提交分路处理；组合输入只提交一次。
- 进程运行与 Agent 正在思考是不同状态。Shell 标记只能证明对应命令的开始/结束；等待输入、就绪、失败等 Agent 状态需要适配器可靠事件，否则显示未知，不能根据几秒无输出猜测。

### 生命周期、数据流与终端兼容性补充

- 明确状态机：Created → Starting → Running → Exiting → Exited / Failed → Disposed；并发 Close/Dispose 幂等，事件含 Session ID，不把一个会话的错误传播给其他会话。
- 每个原生资源写清拥有者和释放 API；创建到一半失败也要逆序释放。主动终止仅作用于本会话拥有的进程树；需要 Job Object 等策略时先验证目标程序兼容性。
- EOF、取消、进程退出和主动关闭不是同一种事件。给等待子进程/排空输出设置有界结束策略，不在 UI 上无限等待；避免不再排空输出却同步等待 ConPTY 结束的死锁。
- VT 状态机要能保留跨读取边界的 CSI/OSC 状态，对超长/未结束序列有恢复策略。未知序列可忽略但不能把尾部当任意执行命令；响应设备查询时遵循真实支持能力，不虚报终端功能。
- 队列达到上限采用背压；只合并渲染通知。终端屏幕有主/备用缓冲与模式状态，普通回滚不是原始 VT 字节日志。
- 临时终端入口仅用于用户主动打开后的交互验证，正常启动仍不得自动运行 Shell。
