# ArkTerminal · Prompt 04：多实例选项卡与会话管理

版本：2026-10-30 · 原始十阶段增强版

使用方式：将本文件全文交给实施 Agent，并明确要求执行本阶段。本文件已包含必要约束与验收，可独立作为阶段 Prompt；运行依赖仍需前序阶段提供。当前交付内容是规划文档。

## 一、任务梗概

建立单窗口多标签工作台，包括新建页、最近项目、项目识别、命令面板和保留标签栏的专注模式，让会话彼此独立且能可靠切换、恢复和关闭。

## 二、前置条件与任务范围

**前置条件：**阶段 1—3 的配置/恢复、Session 与正式 View 可用；中文输入与生命周期门槛已通过。

**本阶段包含：**SessionManager、标签三位置/拖拽/溢出、标题、运行状态、新建页、最近项目、命令面板骨架、全局热键、专注模式及恢复入口。

**阶段边界：**完整工作区、工作区独立配色、多窗口/拖出、分屏与 Quake 后置；阶段 7 提供 Shell 状态、阶段 8 提供 Agent 检测、阶段 9 注册 Skill。

## 三、必须遵守的工程约束

你是 ArkTerminal 的实施 Agent。收到本文件及明确的实施指令后，只执行本阶段；本文件本身不代表用户已要求开始编写应用。

以下是贯穿首版的最终约束；尚未轮到的功能按本阶段范围预留，不提前扩张实现。

- 产品是 Shell 与 Agent 并重的 Windows 10/11 x64 原生 WPF 工作台。保留 `net10.0-windows`、ConPTY 和原生渲染路线；不使用 WebView2/xterm.js，不引入大型 UI 框架。最低 Windows 构建号须以实际依赖和能力验证为准。
- 先读仓库 `AGENTS.md`、解决方案、相关源码和已有阶段交接。原材料描述仓库接近空白，实施时重新核实，保留用户已有改动和稳定公共契约。不要仅因文件名不同就复制一套同职能服务。
- 每个 Session 独立拥有进程、I/O、缓冲和取消源；View 负责显示与输入。UI 线程不做扫描、进程探测、输出解析或阻塞 I/O；队列、缓存、日志、回滚均有上限和释放路径。
- 首版同时支持标准数据目录与便携模式；所有文件访问经统一数据根服务，配置原子写入。标准/MSIX/便携模式的数据默认隔离，不静默迁移或降级覆盖高版本配置。
- 正常启动显示新建页，由用户选择项目或 Agent；崩溃恢复只恢复待确认配置草稿和未启动布局。专注模式保留标签栏。完整工作区、多窗口、分屏和 Quake 在后续版本实现。
- 不自动运行检测到的 Agent，不修改用户 Agent 全局配置，不收集遥测或自动上传正文。应用命令历史和按会话输出保存默认关闭；MCP 首版只读。模型建议的生成、投递与实际执行分别处理。
- 新增依赖先检查替代能力，记录具体包名、固定版本、用途和许可证。项目没有测试基础设施时，不擅自新建测试项目、报告目录或脚手架；已有相关测试可运行，必要应用内诊断应服务真实产品功能。
- 应用始终手动更新，不做云同步、账号、插件商店或主题商店；本地插件/主题导入属于后续版本。不自动 commit、push 或对外发布；本阶段必要的本地构建和文档更新在范围内。

文中的默认上限与时长是实施建议，不是用户逐项指定的硬指标。实现为集中可调整配置；如需调整，在交付中说明原因和实际值，不能悄悄放宽用户已确认的权限与数据边界。

## 四、任务要求

1. 正常启动只显示新建页：最近项目、目录选择、Shell/Profile 与 Agent 入口。无 Agent 时有空态与检测状态；点击入口才启动。最近记录限制数量，提供删除/清空。
2. 轻量识别所选目录及最多 5 层父目录的 .git（文件或目录）、.sln、package.json 等；不递归扫描子树或全盘，遇权限/网络路径可取消，展示建议根目录供选择。
3. SessionManager/TabViewModel 实现新建、关闭、重复、重启和异常退出。重复是按配置新建，不复制进程状态；切换不重启会话或丢回滚。
4. 标签支持顶部/底部水平、左侧垂直；拖拽换位、捕获/取消、插入指示、可中断动画、标题截断及 Tooltip。溢出时可滚动/导航，当前标签自动进入视口。
5. 标题优先固定名称 > Shell 标题 > 可信前台进程 > Profile。显示运行/退出/异常，Agent 细状态仅使用 阶段 7/8 可靠事件。
6. 统一命令注册与面板搜索标签、设置、Profile、Agent、Skill；工作区等未实现能力不显示可执行假入口。Ctrl+Shift+Space 全局呼出可配置/禁用，冲突提示，退出释放注册。
7. 专注模式保留标签栏及最小会话状态，隐藏设置导航与多余装饰；键盘即时切换，不阻塞输入。
8. 异常退出后的新建页提供草稿/布局恢复或丢弃，恢复布局生成未启动占位卡；不自动恢复进程或执行启动后脚本。关闭有运行任务时按设置提示，取消不销毁会话。

### 行为边界与预留

- 新建页同时服务 Shell 和 Agent，最近项目只保存有限路径/显示名，支持删除。首次启动可异步开始检测，但检测结果不得自动触发 Agent 会话。
- 项目识别默认只检查当前目录及最多 5 层父级的标记，.git 可为文件；不递归读取仓库内容。候选根目录由用户选择，已有 cwd 不被静默改写。
- “重复标签”基于 Profile/已明确的 cwd 创建新进程，不复制活进程、输入缓冲或正文；重启保留或清空回滚的规则要明确，默认不把旧输出冒充新会话。
- Shell 标题和进程名尚不可用时回退 Profile；阶段 8/9 尚未交付的入口显示明确不可用原因或不注册，不做可点击假按钮。
- 正常启动始终是新建页；异常恢复只恢复未启动的布局占位与待确认草稿。点击启动前不执行启动后脚本，不触发 UAC，也不恢复转录记录开关。
- 全局命令面板快捷键默认 Ctrl+Shift+Space，注册失败提示冲突，关闭/禁用时释放。面板呼出属于 UI 激活，不等于 Quake 或创建终端。
- 将 Session 所有权和 View 挂接分离，预留移动 View 的能力；本阶段不实现跨窗口进程重建。
